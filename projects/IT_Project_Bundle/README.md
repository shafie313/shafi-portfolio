# IT Support Practical Project Bundle

This bundle contains starter implementations and lab guides for the projects other than NEXUS. NEXUS is intentionally excluded and should remain unchanged in your portfolio.

## Projects

1. **Windows PC Health Check** — PowerShell script that collects basic system, disk and network information and exports CSV + HTML reports.
2. **RHEL Basic Health Check** — Bash script that records host, OS, uptime, memory, disk and selected systemd service information in a timestamped text report.
3. **Windows Server Active Directory Lab** — guided lab plan and sample PowerShell commands for a disposable Windows Server lab.
4. **Cisco VLAN / Inter-VLAN / ACL Lab** — example addressing plan and IOS configuration snippets for Packet Tracer.
5. **Wireless AP & Local File-Sharing Lab** — setup and troubleshooting checklist for a home/office access point and router USB storage where supported.

## Important

- These are practical learning projects, not evidence that a lab has already been run successfully.
- Test scripts only on computers you own or are authorized to support.
- Windows Server AD DS promotion and network configuration can affect connectivity. Use a virtual lab and snapshots.
- Cisco snippets are examples. Adapt interface numbers, device capabilities and addressing to your actual topology before applying them.
- Router USB storage/FTP/Samba features vary by model and firmware; do not expose FTP or router administration directly to the public internet.

## Suggested order

Start with Windows PC Health Check and RHEL Health Check. Then build the Active Directory lab in virtual machines, followed by the Packet Tracer network lab and the wireless/file-sharing checklist.
